# Parallel Timelines

​Parallel Timelines is a sci-fi time travel roguelike game made in 7 days. The ship is about to explode and you are the only one left. Find the keycards and bring them to the escape shuttle before time runs out. Each time you die (or whenever you want) you can jump back in time and try again, but your past selves are there too. You lose the game if any of your past selves sees the current you.

​The game was made during the 7 Day Roguelike Challenge 2026 using [Godot​](https://godotengine.org/).
